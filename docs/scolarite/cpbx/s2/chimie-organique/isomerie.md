## Définition d'isomère

C'est une molécule ayant la même formule brute mais une géométrie différente. Il y a trois types d'isomères :

- conformation ;
- configuration ;
- constitution.

## Isomérie de constitution

Les molécules ont la même formule brute mais des formules développées différentes, elles diffèrent donc dans l'enchaînement des atomes.

## Géométrie moléculaire

Voir le cours sur l'hybridation de chimie générale du semestre 1.

Une hybridation résulte d'une combinaison linéaire de différentes orbitales, ce qui force les atomes à se placer selon une forme qui limite les interactions. Hormis les liaisons $\sigma$ (recouvrement axial), un recouvrement latéral provoque une liaison $\pi$ (plus simple à briser).
