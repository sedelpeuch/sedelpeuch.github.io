Circuits électriques en régime sinusoïdal

Définitions, généralités​

Force de Lorentz​

On définit la force de Lorentz par F⃗=qv⃗∧B⃗\vec{F} = q\vec{v} \wedge \vec{B}F=qv∧B (voir le cours d'électromagnétisme).

Grandeurs périodiques s(t)​

Une grandeur est dite périodique si elle prend les mêmes valeurs à intervalles de temps réguliers :

s(t+T)=s(t)s(t + T) = s(t)s(t+T)=s(t)

où TTT est l'intervalle de temps appelé période (en secondes).

On définit la fréquence f=1Tf = \dfrac{1}{T}f=T1​, qui indique le nombre de cycles par unité de temps (Hz\text{Hz}Hz ou s−1\text{s}^{-1}s−1).

La grandeur physique s(t)s(t)s(t) est dite monodirectionnelle si s(t)s(t)s(t) est de signe constant, et bidirectionnelle si elle change de signe.

La valeur moyenne, notée ⟨s⟩\langle s \rangle⟨s⟩, d'une grandeur est définie par :

⟨s⟩=1T∫0Ts(t) dt\langle s \rangle = \frac{1}{T}\int_0^T s(t)\,dt⟨s⟩=T1​∫0T​s(t)dt

La valeur efficace, notée SeffS_{eff}Seff​, d'une grandeur périodique de période TTT est définie par :

Seff2=1T∫0Ts2(t) dtS_{eff}^2 = \frac{1}{T}\int_0^T s^2(t)\,dtSeff2​=T1​∫0T​s2(t)dt

Grandeurs sinusoïdales​

Soit la grandeur sinusoïdale s(t)=Smcos⁡(ωt+ϕ)s(t) = S_m\cos(\omega t + \phi)s(t)=Sm​cos(ωt+ϕ).

  • Sa valeur instantanée est s(t)s(t)s(t).
  • Sa valeur maximale, ou valeur crête, est SmS_mSm​.
  • Sa pulsation est ω\omegaω, la période est T=2πωT = \dfrac{2\pi}{\omega}T=ω2π​. La fréquence est f=1T=ω2πf = \dfrac{1}{T} = \dfrac{\omega}{2\pi}f=T1​=2πω​.
  • Sa phase (à l'origine) est ϕ\phiϕ.
  • La valeur moyenne d'une grandeur sinusoïdale est ⟨s⟩=0\langle s \rangle = 0⟨s⟩=0.
  • La valeur efficace est Seff=Sm2⇒s(t)=Seff2cos⁡(ωt+ϕ)S_{eff} = \dfrac{S_m}{\sqrt{2}} \Rightarrow s(t) = S_{eff}\sqrt{2}\cos(\omega t + \phi)Seff​=2​Sm​​⇒s(t)=Seff​2​cos(ωt+ϕ).
