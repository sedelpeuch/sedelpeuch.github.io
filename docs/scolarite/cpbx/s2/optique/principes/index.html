Grands principes de l'optique géométrique et prisme

Principe de Fermat​

Énoncé. Le chemin emprunté par la lumière pour aller d'un point à un autre est celui pour lequel le temps de parcours est minimum.

Conséquences​

  • Milieu transparent homogène = propagation rectiligne.
  • Rayon lumineux = droite représentant la trajectoire de la lumière.

Dans un milieu transparent autre que le vide : v=cnv = \dfrac{c}{n}v=nc​, où nnn est l'indice de réfraction1 du milieu.

Loi de Cauchy​

L'indice de réfraction dépend de la longueur d'onde de la lumière se propageant dans le milieu2.

n(λ)=A+Bλ2n(\lambda) = A + \frac{B}{\lambda^2}n(λ)=A+λ2B​

Lois de Snell-Descartes​

Énoncé 1. Les rayons réfractés et réfléchis sont dans le plan d'incidence.

Énoncé 2. i1=−i1′i_1 = -i'_1i1​=−i1′​

Énoncé 3. n1sin⁡(i1)=n2sin⁡(i2)n_1 \sin(i_1) = n_2 \sin(i_2)n1​sin(i1​)=n2​sin(i2​)

Remarques​

  • Si les deux indices sont positifs, alors le rayon réfracté et le rayon incident sont de part et d'autre de la normale.
  • n1>n2n_1 > n_2n1​>n2​ : le rayon s'écarte de la normale.
  • n1<n2n_1 < n_2n1​<n2​ : le rayon se rapproche de la normale.
  • Si l'angle est petit, on a la loi de Kepler : n1i1=n2i2n_1 i_1 = n_2 i_2n1​i1​=n2​i2​.
  • Principe de retour inverse de la lumière.

Réfraction limite, réflexion totale​

Ce sont les cas limites, conséquences de la troisième loi de Snell.

Réfraction limite​

  • Pour i1=0∘⇒i2=0∘i_1 = 0^\circ \Rightarrow i_2 = 0^\circi1​=0∘⇒i2​=0∘.
  • Pour 0∘<i1<90∘⇒0∘<i2<i10^\circ < i_1 < 90^\circ \Rightarrow 0^\circ < i_2 < i_10∘<i1​<90∘⇒0∘<i2​<i1​.
  • Pour i1=90∘⇒sin⁡ilim=n1n2i_1 = 90^\circ \Rightarrow \sin i_{lim} = \dfrac{n_1}{n_2}i1​=90∘⇒sinilim​=n2​n1​​.

Réflexion totale​

  • Pour i1=0∘⇒i2=0∘i_1 = 0^\circ \Rightarrow i_2 = 0^\circi1​=0∘⇒i2​=0∘.
  • Pour 0∘<i1<90∘⇒i2>i10^\circ < i_1 < 90^\circ \Rightarrow i_2 > i_10∘<i1​<90∘⇒i2​>i1​.
  • Pour i2=90∘⇒sin⁡(iR)=n2n1<1i_2 = 90^\circ \Rightarrow \sin(i_R) = \dfrac{n_2}{n_1} < 1i2​=90∘⇒sin(iR​)=n1​n2​​<1.
  • Pour i1>iR⇒i_1 > i_R \Rightarrowi1​>iR​⇒ rayon totalement réfléchi.

Lame à faces parallèles​

  • Si n1≠n3n_1 \neq n_3n1​=n3​, la réfraction ne dépend pas de n2n_2n2​ : on a n1sin⁡(i1)=n3sin⁡(i3)n_1 \sin(i_1) = n_3 \sin(i_3)n1​sin(i1​)=n3​sin(i3​).
  • Si n1=n3n_1 = n_3n1​=n3​, le rayon émerge de manière parallèle mais décalé de ecos⁡i2sin⁡(i1−i2)\dfrac{e}{\cos i_2} \sin(i_1 - i_2)cosi2​e​sin(i1​−i2​).

Prisme​

Définitions​

Prisme : milieu transparent d'indice de réfraction nnn limité par deux faces planes formant un dièdre. On assimile le prisme à un plan perpendiculaire triangulaire.

Dispersion : décomposition de la lumière en ses différentes longueurs d'onde.

Marche d'un rayon dans une section principale du prisme, formules du prisme​

  • Face d'entrée : sin⁡(i)=nsin⁡(r)\sin(i) = n \sin(r)sin(i)=nsin(r).
  • Face de sortie : nsin⁡(r′)=sin⁡(i′)n \sin(r') = \sin(i')nsin(r′)=sin(i′).
  • A=r+r′A = r + r'A=r+r′.
  • D=i+i′−AD = i + i' - AD=i+i′−A.

Conditions d'émergence du rayon​

Il faut que 2iR>A2 i_R > A2iR​>A et que i>i0⇔sin⁡(i0)=nsin⁡(A−iR)i > i_0 \Leftrightarrow \sin(i_0) = n \sin(A - i_R)i>i0​⇔sin(i0​)=nsin(A−iR​).

Minimum de déviation​

L'angle d'incidence iii est compris entre i0i_0i0​ et π/2\pi/2π/2 ; ce minimum se produit quand i=i′i = i'i=i′, donc

n=sin⁡A+Dm2sin⁡A2n = \frac{\sin \dfrac{A + D_m}{2}}{\sin \dfrac{A}{2}}n=sin2A​sin2A+Dm​​​

Dispersion​

Rappel de la loi de Cauchy : n(λ)=A+Bλ2n(\lambda) = A + \dfrac{B}{\lambda^2}n(λ)=A+λ2B​.

Le prisme décompose la lumière blanche en ses composantes. Raisonnement sur le bleu et le rouge :

  • λR>λB⇒nR<nB\lambda_R > \lambda_B \Rightarrow n_R < n_BλR​>λB​⇒nR​<nB​ ;
  • face d'entrée : sin⁡(i)=nRsin⁡rr=nBsin⁡rB\sin(i) = n_R \sin r_r = n_B \sin r_Bsin(i)=nR​sinrr​=nB​sinrB​ ;
  • ⇒rr>rB\Rightarrow r_r > r_B⇒rr​>rB​, donc décomposition de la lumière.

Footnotes​

  1. Plus l'indice de réfraction est élevé, plus le milieu est réfringent. ↩
