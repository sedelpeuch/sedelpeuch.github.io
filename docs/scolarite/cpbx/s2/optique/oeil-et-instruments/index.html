Œil et instruments d'optique

Œil et vision​

L'accommodation​

Pour avoir une image nette, il faut que la distance focale f′f'f′ du cristallin varie pour que l'image A′A'A′ se forme sur la rétine, quelle que soit la position de l'objet AAA :

1OA′‾−1OA‾=1f′=(n−1)(1R1−1R2)\frac{1}{\overline{OA'}} - \frac{1}{\overline{OA}} = \frac{1}{f'} = (n - 1)\left(\frac{1}{R_1} - \frac{1}{R_2}\right)OA′1​−OA1​=f′1​=(n−1)(R1​1​−R2​1​)

Pour un œil emmétrope :

Œil au repos : vision nette à une distance DMD_MDM​ (infinie), c'est le punctum remotum.

Fatigue maximale : vision nette à une distance DmD_mDm​ (20 cm), c'est le punctum proximum.

Soit AAA un objet situé à la distance DDD de l'œil ; on pose 1f′=C\dfrac{1}{f'} = Cf′1​=C et OA′‾=1K\overline{OA'} = \dfrac{1}{K}OA′=K1​.

C−1D=KC - \frac{1}{D} = KC−D1​=K

Accommodation maximale : C0+ΔC−1Dm=KC_0 + \Delta C - \dfrac{1}{D_m} = KC0​+ΔC−Dm​1​=K.

ΔC=1Dm−1DM\Delta C = \frac{1}{D_m} - \frac{1}{D_M}ΔC=Dm​1​−DM​1​

Les défauts optiques de l'œil​

Myope. Au repos, F′F'F′ est situé devant la rétine ; ainsi, le PR est à distance finie et les objets lointains sont flous, le PP est situé plus près de l'œil. Pour le corriger, il faut ajouter une lentille divergente de focale f1′=−DMf'_1 = -D_Mf1′​=−DM​ ; ainsi le PR est corrigé, et le PP aussi.

Hypermétrope. Au repos, F′F'F′ est situé derrière la rétine ; ainsi, le PR est virtuel et le PP est plus loin de l'œil. Pour le corriger, il faut accoler une lentille convergente de distance focale f1′=−DMf'_1 = -D_Mf1′​=−DM​ ; ainsi le PR est corrigé, et le PP aussi.

Presbytie. Avec l'âge, l'amplitude dioptrique diminue : le PR reste à l'infini mais le PP s'éloigne progressivement. Correction par des verres convergents (verres progressifs).

L'astigmatisme. La cornée n'est pas parfaitement sphérique : il n'y a pas de mise au point simultanée possible sur les lignes verticales et horizontales.

Instruments d'optique​

Introduction​

Il y a deux types d'IO : les objectifs (image réelle sur un écran) et les oculaires (image virtuelle rejetée à l'infini).

Grossissement : grandeur de l'image par rapport à celle de l'objet.

Champ : portion de l'espace vue à travers l'IO.

Pouvoir séparateur : distance angulaire entre les deux points les plus proches dont l'IO donne deux images distinctes.

Clarté : rendement photométrique.

Principe. La loupe est une lentille convergente de quelques centimètres de distance focale. L'image doit être agrandie et droite, donc l'objet ABABAB doit être placé entre le foyer objet FFF et le centre optique OOO.

La lunette astronomique​

L'objet est à l'infini, réel, très gros mais très loin, donc de très faible hauteur angulaire α\alphaα.

La lunette terrestre​

Avec une lunette astronomique, on perçoit l'image à l'envers ; pour l'utiliser sur terre, il faut donc insérer un montage pour la retourner.
