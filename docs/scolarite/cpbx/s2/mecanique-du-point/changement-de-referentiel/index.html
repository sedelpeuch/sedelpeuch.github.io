Changement de référentiel

Définitions​

Vitesse absolue va⃗\vec{v_a}va​​ : vitesse du point MMM évaluée dans le référentiel (R)(R)(R).

Accélération absolue aa⃗\vec{a_a}aa​​ : accélération du point MMM évaluée dans le référentiel absolu (R)(R)(R).

Vitesse relative vr⃗\vec{v_r}vr​​ : vitesse du point MMM évaluée dans le référentiel relatif (R′)(R')(R′).

Accélération relative ar⃗\vec{a_r}ar​​ : accélération du point MMM évaluée dans le référentiel relatif (R′)(R')(R′).

Notion d'entraînement : le point coïncidant est le point PPP qui coïncide avec MMM à l'instant ttt et qui est fixe dans (R′)(R')(R′). On a donc :

  • vitesse d'entraînement ve⃗\vec{v_e}ve​​ : vitesse du point coïncidant PPP évaluée dans le référentiel fixe (R)(R)(R) ;
  • accélération d'entraînement ae⃗\vec{a_e}ae​​ : accélération du point coïncidant PPP évaluée dans le référentiel fixe (R)(R)(R).

Dérivée d'un vecteur​

U⃗=x ex⃗+y ey⃗+z ez⃗=x′ ex′⃗+y′ ey′⃗+z′ ez′⃗\vec{U} = x\,\vec{e_x} + y\,\vec{e_y} + z\,\vec{e_z} = x'\,\vec{e'_x} + y'\,\vec{e'_y} + z'\,\vec{e'_z}U=xex​​+yey​​+zez​​=x′ex′​​+y′ey′​​+z′ez′​​
(dv⃗dt)(R)=(dv⃗dt)(R′)+ω⃗(R′/R)∧v⃗\left(\frac{d\vec{v}}{dt}\right)_{(R)} = \left(\frac{d\vec{v}}{dt}\right)_{(R')} + \vec{\omega}(R'/R) \wedge \vec{v}(dtdv​)(R)​=(dtdv​)(R′)​+ω(R′/R)∧v

Transformation des vitesses et des accélérations​

Composition des vitesses​

va⃗=vr⃗+ve⃗\vec{v_a} = \vec{v_r} + \vec{v_e}va​​=vr​​+ve​​

Composition des accélérations​

aa⃗=ar⃗+ae⃗+ac⃗\vec{a_a} = \vec{a_r} + \vec{a_e} + \vec{a_c}aa​​=ar​​+ae​​+ac​​

avec

ae⃗=d2OO′→dt2∣R+dω⃗(R′/R)dt∧O′P→+ω⃗(R′/R)∧(ω⃗(R′/R)∧O′P→)\vec{a_e} = \left.\frac{d^2\overrightarrow{OO'}}{dt^2}\right|_R + \frac{d\vec{\omega}(R'/R)}{dt} \wedge \overrightarrow{O'P} + \vec{\omega}(R'/R) \wedge \left(\vec{\omega}(R'/R) \wedge \overrightarrow{O'P}\right)ae​​=dt2d2OO′​​R​+dtdω(R′/R)​∧O′P+ω(R′/R)∧(ω(R′/R)∧O′P)

et

ac⃗=2 ω⃗(R′/R)∧vr⃗(M/R′)\vec{a_c} = 2\,\vec{\omega}(R'/R) \wedge \vec{v_r}(M/R')ac​​=2ω(R′/R)∧vr​​(M/R′)

Dynamique dans un référentiel non galiléen​

On considère (R)(R)(R) fixe et galiléen ; (R′)(R')(R′) est mobile par rapport à (R)(R)(R), ainsi (R′)(R')(R′) n'est pas galiléen.

Relation fondamentale de la dynamique​

f⃗=maa⃗\vec{f} = m\vec{a_a}f​=maa​​

donc

f⃗−mae⃗−mac⃗=mar⃗\vec{f} - m\vec{a_e} - m\vec{a_c} = m\vec{a_r}f​−mae​​−mac​​=mar​​

On obtient donc

f⃗+fie⃗+fic⃗=mar⃗\vec{f} + \vec{f_{ie}} + \vec{f_{ic}} = m\vec{a_r}f​+fie​​+fic​​=mar​​

où fie⃗=−mae⃗\vec{f_{ie}} = -m\vec{a_e}fie​​=−mae​​ et fic⃗=−mac⃗\vec{f_{ic}} = -m\vec{a_c}fic​​=−mac​​.

Cas particuliers​

Translation rectiligne : ac⃗=0⃗\vec{a_c} = \vec{0}ac​​=0.

Rotation uniforme autour d'un axe fixe : on a vr⃗=0⃗\vec{v_r} = \vec{0}vr​​=0 et fie⃗=mω2 OM→\vec{f_{ie}} = m\omega^2\,\overrightarrow{OM}fie​​=mω2OM.

Point matériel immobile​

Un point matériel MMM est immobile dans (R′)(R')(R′) si le vecteur O′M→\overrightarrow{O'M}O′M est constant, donc f⃗−mae⃗=0⃗\vec{f} - m\vec{a_e} = \vec{0}f​−mae​​=0.
