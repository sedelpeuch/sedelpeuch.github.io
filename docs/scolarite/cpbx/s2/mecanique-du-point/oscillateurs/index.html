Oscillateurs

Oscillations libres​

Mouvement d'un point matériel au voisinage d'une position d'équilibre​

Par définition, on appelle oscillateur harmonique à une dimension un point matériel mobile repéré par un paramètre dont le mouvement est décrit par une équation différentielle de la forme ci-dessous :

d2Xdt2+ω02X=0avecω02=km\frac{d^2X}{dt^2} + \omega_0^2 X = 0 \quad \text{avec} \quad \omega_0^2 = \frac{k}{m}dt2d2X​+ω02​X=0avecω02​=mk​

Description du mouvement​

La solution de l'équation ci-dessus est X(t)=Acos⁡(ω0t+ϕ)X(t) = A\cos(\omega_0 t + \phi)X(t)=Acos(ω0​t+ϕ), avec

{A:amplitudeϕ:phaseω0:pulsation propre du mouvement\begin{cases} A : \text{amplitude} \\ \phi : \text{phase} \\ \omega_0 : \text{pulsation propre du mouvement} \end{cases}⎩⎨⎧​A:amplitudeϕ:phaseω0​:pulsation propre du mouvement​

Le mouvement de l'oscillateur harmonique à une dimension est périodique. La période vaut T0=2πω0T_0 = \dfrac{2\pi}{\omega_0}T0​=ω0​2π​.
