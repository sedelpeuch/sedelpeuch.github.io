Probabilités sur un univers fini

Épreuve​

Définition. On dit qu'une expérience ou une épreuve est aléatoire si on obtient des résultats différents lorsqu'on répète les mêmes expériences avec les mêmes données.

Exemple.

  • Lancer une pièce de monnaie.
  • Tirage d'une carte parmi 32 cartes.

Ensemble des éventualités (ou univers)​

Définition. Considérons une épreuve aléatoire. L'ensemble des éventualités de cette épreuve est l'ensemble des résultats possibles. On note cet ensemble Ω\OmegaΩ.

Exemple.

  • Lancer une pièce de monnaie une fois : Ω={Pile,Face}\Omega = \{\text{Pile}, \text{Face}\}Ω={Pile,Face}
  • Lancer une pièce de monnaie deux fois : Ω={(Pile,Face),(Pile,Pile),(Face,Pile),(Face,Face)}\Omega = \{(\text{Pile}, \text{Face}), (\text{Pile}, \text{Pile}), (\text{Face}, \text{Pile}), (\text{Face}, \text{Face})\}Ω={(Pile,Face),(Pile,Pile),(Face,Pile),(Face,Face)}
  • Le cardinal d'une telle expérience est card(Ω)=2k\text{card}(\Omega) = 2^kcard(Ω)=2k.

Définition. Soit Ω\OmegaΩ l'espace des éventualités associé à une épreuve aléatoire. On note P(Ω)\mathcal{P}(\Omega)P(Ω) l'ensemble des parties de Ω\OmegaΩ. Chaque élément de P(Ω)\mathcal{P}(\Omega)P(Ω) (c'est-à-dire chaque partie de Ω\OmegaΩ) est appelé un événement.

Exemple. Si on lance une pièce de monnaie 3 fois, A={(P,P,F),(P,P,P)}A = \{(P, P, F), (P, P, P)\}A={(P,P,F),(P,P,P)} est un événement.

Événements particuliers.

  1. ∅\emptyset∅ est appelé événement impossible.

  2. Ω\OmegaΩ est appelé événement certain.

  3. Soient AAA et BBB deux parties de Ω\OmegaΩ ; AAA et BBB sont incompatibles si

    A∩B=∅A \cap B = \emptysetA∩B=∅

  4. Chaque partie de Ω\OmegaΩ constituée d'un seul élément est appelée événement élémentaire (un événement élémentaire est une éventualité).

Probabilité finie​

Définition. Soit Ω\OmegaΩ un univers et P(Ω)\mathcal{P}(\Omega)P(Ω) l'ensemble des événements de Ω\OmegaΩ. Une probabilité ppp est une application de P(Ω)\mathcal{P}(\Omega)P(Ω) dans [0,1][0, 1][0,1] qui vérifie les propriétés suivantes :

p:P(Ω)→[0,1]p : \mathcal{P}(\Omega) \to [0, 1]p:P(Ω)→[0,1]
  1. p(∅)=0p(\emptyset) = 0p(∅)=0, p(Ω)=1p(\Omega) = 1p(Ω)=1
  2. ∀A,B∈P(Ω)\forall A, B \in \mathcal{P}(\Omega)∀A,B∈P(Ω) tels que A∩B=∅A \cap B = \emptysetA∩B=∅, on a p(A∪B)=p(A)+p(B)p(A \cup B) = p(A) + p(B)p(A∪B)=p(A)+p(B)

Le triplet (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) est appelé espace de probabilité.

Corollaire. Si (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) est un espace de probabilité, alors ∀A1,A2,…,An∈P(Ω)\forall A_1, A_2, \dots, A_n \in \mathcal{P}(\Omega)∀A1​,A2​,…,An​∈P(Ω) tels que Ai∩Aj=∅A_i \cap A_j = \emptysetAi​∩Aj​=∅, i≠ji \neq ji=j, on a :

p(⋃i=1nAi)=∑i=1np(Ai)p\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} p(A_i)p(i=1⋃n​Ai​)=i=1∑n​p(Ai​)

Démonstration par récurrence. Par hypothèse, pour A1,A2A_1, A_2A1​,A2​ tels que A1∩A2=∅A_1 \cap A_2 = \emptysetA1​∩A2​=∅, on a p(A1∪A2)=p(A1)+p(A2)p(A_1 \cup A_2) = p(A_1) + p(A_2)p(A1​∪A2​)=p(A1​)+p(A2​). Supposons que p(A1∪A2∪⋯∪An)=p(A1)+p(A2)+⋯+p(An)p(A_1 \cup A_2 \cup \dots \cup A_n) = p(A_1) + p(A_2) + \dots + p(A_n)p(A1​∪A2​∪⋯∪An​)=p(A1​)+p(A2​)+⋯+p(An​) ; alors p(A1∪A2∪⋯∪An∪An+1)=p(A1)+⋯+p(An)+p(An+1)p(A_1 \cup A_2 \cup \dots \cup A_n \cup A_{n+1}) = p(A_1) + \dots + p(A_n) + p(A_{n+1})p(A1​∪A2​∪⋯∪An​∪An+1​)=p(A1​)+⋯+p(An​)+p(An+1​). L'hypothèse de récurrence est vraie pour n+1n + 1n+1.

  2. p(Ω∖A)=1−p(A)p(\Omega \setminus A) = 1 - p(A)p(Ω∖A)=1−p(A)

    Donc p(A∪B)=(p(A)−p(A∩B))+p(B)−p(A∩B)+p(A∩B)p(A \cup B) = (p(A) - p(A \cap B)) + p(B) - p(A \cap B) + p(A \cap B)p(A∪B)=(p(A)−p(A∩B))+p(B)−p(A∩B)+p(A∩B).

  2. Ω=(Ω∖A)∪A\Omega = (\Omega \setminus A) \cup AΩ=(Ω∖A)∪A, (Ω∖A)∩A=∅(\Omega \setminus A) \cap A = \emptyset(Ω∖A)∩A=∅

    ⇔p(Ω)=p(Ω∖A)+p(A)=1⇒p(Ω∖A)=1−p(A)\Leftrightarrow p(\Omega) = p(\Omega \setminus A) + p(A) = 1 \Rightarrow p(\Omega \setminus A) = 1 - p(A)⇔p(Ω)=p(Ω∖A)+p(A)=1⇒p(Ω∖A)=1−p(A)

  3. Si A⊂BA \subset BA⊂B, alors B=A∪(B∖A)B = A \cup (B \setminus A)B=A∪(B∖A) et on a A∩(B∖A)=∅A \cap (B \setminus A) = \emptysetA∩(B∖A)=∅ :

    p(B)=p(A)+p(B∖A)≥p(A)car ∀c∈P(Ω),p(c)≥0p(B) = p(A) + p(B \setminus A) \geq p(A) \quad \text{car } \forall c \in \mathcal{P}(\Omega), p(c) \geq 0p(B)=p(A)+p(B∖A)≥p(A)car ∀c∈P(Ω),p(c)≥0

Équiprobabilité​

Définition. Soit (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) un espace de probabilité. On dit que deux événements élémentaires sont équiprobables si p({a1})=p({a2})p(\{a_1\}) = p(\{a_2\})p({a1​})=p({a2​}).

Théorème VII.2. Soit (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) un espace de probabilité tel que tous les événements élémentaires sont équiprobables (on rappelle que Ω\OmegaΩ est un ensemble fini). Alors on a :

  1. ∀a∈Ω\forall a \in \Omega∀a∈Ω, p({a})=1card(Ω)p(\{a\}) = \dfrac{1}{\text{card}(\Omega)}p({a})=card(Ω)1​
  2. ∀A∈P(Ω)\forall A \in \mathcal{P}(\Omega)∀A∈P(Ω), p(A)=card(A)card(Ω)p(A) = \dfrac{\text{card}(A)}{\text{card}(\Omega)}p(A)=card(Ω)card(A)​

Démonstration. Ω={a1,a2,…,an}\Omega = \{a_1, a_2, \dots, a_n\}Ω={a1​,a2​,…,an​}, alors

p(Ω)=p(⋃i=1n{ai})=∑i=1np({ai})=1=n p({ai})car p({ai})=p({aj}),∀i,jp(\Omega) = p\left(\bigcup_{i=1}^{n} \{a_i\}\right) = \sum_{i=1}^{n} p(\{a_i\}) = 1 = n\,p(\{a_i\}) \quad \text{car } p(\{a_i\}) = p(\{a_j\}), \forall i, jp(Ω)=p(i=1⋃n​{ai​})=i=1∑n​p({ai​})=1=np({ai​})car p({ai​})=p({aj​}),∀i,j
⇒p({ai})=1n=1card(Ω)\Rightarrow p(\{a_i\}) = \frac{1}{n} = \frac{1}{\text{card}(\Omega)}⇒p({ai​})=n1​=card(Ω)1​

Soit A={a1,a2,…,ak}⊂ΩA = \{a_1, a_2, \dots, a_k\} \subset \OmegaA={a1​,a2​,…,ak​}⊂Ω et p(A)=p({a1,a2,…,ak})=∑i=1kp({ai})=k p({ai})=kn=card(A)card(Ω)p(A) = p(\{a_1, a_2, \dots, a_k\}) = \displaystyle\sum_{i=1}^{k} p(\{a_i\}) = k\,p(\{a_i\}) = \frac{k}{n} = \frac{\text{card}(A)}{\text{card}(\Omega)}p(A)=p({a1​,a2​,…,ak​})=i=1∑k​p({ai​})=kp({ai​})=nk​=card(Ω)card(A)​.

Théorème VII.5 (Théorème de Bayes). Soit (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) un espace de probabilité. Soient A,B∈P(Ω)A, B \in \mathcal{P}(\Omega)A,B∈P(Ω) tels que p(B)≠0p(B) \neq 0p(B)=0 et p(A)≠0p(A) \neq 0p(A)=0.
