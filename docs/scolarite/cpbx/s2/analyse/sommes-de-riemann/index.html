S{c0,…,cn}f=∑i=0n−1(ci+1−ci)f(ξi)S^f_{\{c_0, \dots, c_n\}} = \sum_{i=0}^{n-1} (c_{i+1} - c_i) f(\xi_i)S{c0​,…,cn​}f​=i=0∑n−1​(ci+1​−ci​)f(ξi​)

Lemme. Soit f:[a,b]→Cf : [a, b] \to \mathbb{C}f:[a,b]→C une fonction de classe C1C^1C1. On a : ∣f(x)−f(y)∣≤∣x−y∣sup⁡∣f′(t)∣|f(x) - f(y)| \leq |x - y| \sup|f'(t)|∣f(x)−f(y)∣≤∣x−y∣sup∣f′(t)∣.

Démonstration.

f(x)−f(y)=∫yxf′(t) dt⇒∣f(x)−f(y)∣=∣∫yxf′(t) dt∣≤∣∫yxsup⁡∣f′(t)∣ dt∣=∣x−y∣sup⁡∣f′(t)∣f(x) - f(y) = \int_y^x f'(t)\,dt \Rightarrow |f(x) - f(y)| = \left|\int_y^x f'(t)\,dt\right| \leq \left|\int_y^x \sup|f'(t)|\,dt\right| = |x - y| \sup|f'(t)|f(x)−f(y)=∫yx​f′(t)dt⇒∣f(x)−f(y)∣=​∫yx​f′(t)dt​≤​∫yx​sup∣f′(t)∣dt​=∣x−y∣sup∣f′(t)∣

Remarque. En général, si f:[a,b]→Cf : [a, b] \to \mathbb{C}f:[a,b]→C est une fonction telle qu'il existe MMM tel que :

∣f(x)−f(y)∣≤M∣x−y∣|f(x) - f(y)| \leq M|x - y|∣f(x)−f(y)∣≤M∣x−y∣

on dit que fff est lipschitzienne. Le lemme précédent montre que si fff est C1C^1C1 alors fff est lipschitzienne.
