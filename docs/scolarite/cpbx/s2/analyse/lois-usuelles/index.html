Variables aléatoires indépendantes​

Définition. Soit (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) un espace de probabilité et X,YX, YX,Y deux variables aléatoires. On dit que XXX et YYY sont indépendantes si et seulement si ∀x∈X(Ω),∀y∈Y(Ω)\forall x \in X(\Omega), \forall y \in Y(\Omega)∀x∈X(Ω),∀y∈Y(Ω) :

p([X=x]∩[Y=y])=p(X=x)×p(Y=y)p([X = x] \cap [Y = y]) = p(X = x) \times p(Y = y)p([X=x]∩[Y=y])=p(X=x)×p(Y=y)

On rappelle que

[X=x]∩[Y=y]={ω∈Ω;X(ω)=x}∩{ω∈Ω;Y(ω)=y}[X = x] \cap [Y = y] = \{\omega \in \Omega ; X(\omega) = x\} \cap \{\omega \in \Omega ; Y(\omega) = y\}[X=x]∩[Y=y]={ω∈Ω;X(ω)=x}∩{ω∈Ω;Y(ω)=y}

Proposition. Soient XXX et YYY deux variables aléatoires indépendantes. Alors :

V(X+Y)=V(X)+V(Y)V(X + Y) = V(X) + V(Y)V(X+Y)=V(X)+V(Y)

Remarque. En général V(X+Y)≠V(X)+V(Y)V(X + Y) \neq V(X) + V(Y)V(X+Y)=V(X)+V(Y), mais on a toujours E(X+Y)=E(X)+E(Y)E(X + Y) = E(X) + E(Y)E(X+Y)=E(X)+E(Y).

Uniforme. Soit (Ω,P(Ω),p)(\Omega, \mathcal{P}(\Omega), p)(Ω,P(Ω),p) un espace de probabilité. Soit XXX une variable aléatoire avec X(Ω)={x1,x2,…,xn}X(\Omega) = \{x_1, x_2, \dots, x_n\}X(Ω)={x1​,x2​,…,xn​}. On dit que XXX suit une loi uniforme si et seulement si :

p(X=xi)=p(X=xj),∀i,jp(X = x_i) = p(X = x_j), \forall i, jp(X=xi​)=p(X=xj​),∀i,j

Donc p(X=xi)=1np(X = x_i) = \dfrac{1}{n}p(X=xi​)=n1​ car p(X=x1)+p(X=x2)+⋯+p(X=xn)=1⇒n p(X=xi)=1p(X = x_1) + p(X = x_2) + \dots + p(X = x_n) = 1 \Rightarrow n\,p(X = x_i) = 1p(X=x1​)+p(X=x2​)+⋯+p(X=xn​)=1⇒np(X=xi​)=1.

Loi de Bernoulli​

Soit une expérience aléatoire qui a deux résultats possibles. Donc l'univers est Ω={ω1,ω2}\Omega = \{\omega_1, \omega_2\}Ω={ω1​,ω2​}. On définit sur Ω\OmegaΩ une probabilité avec :

p(ω1)=petp(ω2)=1−pp(\omega_1) = p \quad \text{et} \quad p(\omega_2) = 1 - pp(ω1​)=petp(ω2​)=1−p

La probabilité est bien définie par la donnée de p(ω1)=pp(\omega_1) = pp(ω1​)=p. On définit la variable aléatoire XXX par :

X:{Ω={ω1,ω2}→{0,1}ω1→1ω2→0X : \begin{cases} \Omega = \{\omega_1, \omega_2\} \to \{0, 1\} \\ \omega_1 \to 1 \\ \omega_2 \to 0 \end{cases}X:⎩⎨⎧​Ω={ω1​,ω2​}→{0,1}ω1​→1ω2​→0​

Donc la loi de XXX est p(X=1)=p(ω1)=pp(X = 1) = p(\omega_1) = pp(X=1)=p(ω1​)=p et p(X=0)=p(ω2)=1−pp(X = 0) = p(\omega_2) = 1 - pp(X=0)=p(ω2​)=1−p. On dit que XXX suit la loi de Bernoulli de paramètre ppp. On note X=B(p)X = \mathcal{B}(p)X=B(p).

Théorème IX.2. Soit X=B(p)X = \mathcal{B}(p)X=B(p). Alors E(X)=pE(X) = pE(X)=p et V(X)=p(1−p)V(X) = p(1 - p)V(X)=p(1−p).

Démonstration. E(X)=1 p(X=1)+0 p(X=0)=p(X=1)=pE(X) = 1\,p(X = 1) + 0\,p(X = 0) = p(X = 1) = pE(X)=1p(X=1)+0p(X=0)=p(X=1)=p, et

V(X)=12p(X=1)+02p(X=0)−p2=p(X=1)−p2=p−p2=p(1−p)V(X) = 1^2 p(X = 1) + 0^2 p(X = 0) - p^2 = p(X = 1) - p^2 = p - p^2 = p(1 - p)V(X)=12p(X=1)+02p(X=0)−p2=p(X=1)−p2=p−p2=p(1−p)

Loi binomiale de paramètres nnn et ppp : B(n,p)\mathcal{B}(n, p)B(n,p)​

Définition. La loi binomiale de paramètres nnn et ppp, notée B(n,p)\mathcal{B}(n, p)B(n,p), est la loi de probabilité d'une variable aléatoire X=X1+X2+⋯+XnX = X_1 + X_2 + \dots + X_nX=X1​+X2​+⋯+Xn​ où chaque XiX_iXi​ est une épreuve de Bernoulli de paramètre ppp (c'est-à-dire Xi=B(p)X_i = \mathcal{B}(p)Xi​=B(p)) possédant la propriété suivante : les variables aléatoires sont indépendantes, c'est-à-dire ∀i≠j\forall i \neq j∀i=j, XiX_iXi​ et XjX_jXj​ sont indépendantes.

Théorème IX.3. XXX est une variable aléatoire binomiale de paramètres nnn et ppp si et seulement si :

  1. X:Ω→{0,1,2,…,n}X : \Omega \to \{0, 1, 2, \dots, n\}X:Ω→{0,1,2,…,n}
  2. p(X=k)=Cnkpk(1−p)n−k,∀k=0,1,2,…,np(X = k) = C_n^k p^k (1 - p)^{n-k}, \forall k = 0, 1, 2, \dots, np(X=k)=Cnk​pk(1−p)n−k,∀k=0,1,2,…,n

Démonstration. Xi=B(p)X_i = \mathcal{B}(p)Xi​=B(p), donc :

Xi:Ω→{0,1}X=X1+X2+⋯+Xn:Ω→{0,1,2,…,n}X_i : \Omega \to \{0, 1\} \qquad X = X_1 + X_2 + \dots + X_n : \Omega \to \{0, 1, 2, \dots, n\}Xi​:Ω→{0,1}X=X1​+X2​+⋯+Xn​:Ω→{0,1,2,…,n}

Démontrons le point 2 par récurrence sur nnn. Montrons le cas n=2n = 2n=2 : X=X1+X2X = X_1 + X_2X=X1​+X2​, X:Ω→{0,1,2}X : \Omega \to \{0, 1, 2\}X:Ω→{0,1,2}.

p(X=0)=p(X1+X2=0)=p(X1=0 et X2=0)=p(X1=0)×p(X2=0)p(X = 0) = p(X_1 + X_2 = 0) = p(X_1 = 0 \text{ et } X_2 = 0) = p(X_1 = 0) \times p(X_2 = 0)p(X=0)=p(X1​+X2​=0)=p(X1​=0 et X2​=0)=p(X1​=0)×p(X2​=0)

car X1X_1X1​ et X2X_2X2​ sont indépendantes.

p(X=0)=p(X1=0)×p(X2=0)=(1−p)(1−p)=(1−p)2=C20p0(1−p)2p(X=1)=p(X1+X2=1)=p{(X1=0 et X2=1) ou (X1=1 et X2=0)}=p(X1=0 et X2=1)+p(X1=1 et X2=0)=p(X1=0)×p(X2=1)+p(X1=1)×p(X2=0)=(1−p)p+p(1−p)=2p(1−p)=C21p1(1−p)2−1p(X=2)=p(X1+X2=2)=p(X1=1 et X2=1)=p(X1=1)×p(X2=1)=p2=C22p2(1−p)2−2\begin{aligned} p(X = 0) &= p(X_1 = 0) \times p(X_2 = 0) = (1 - p)(1 - p) = (1 - p)^2 = C_2^0 p^0 (1 - p)^2 \\ p(X = 1) &= p(X_1 + X_2 = 1) = p\{(X_1 = 0 \text{ et } X_2 = 1) \text{ ou } (X_1 = 1 \text{ et } X_2 = 0)\} \\ &= p(X_1 = 0 \text{ et } X_2 = 1) + p(X_1 = 1 \text{ et } X_2 = 0) \\ &= p(X_1 = 0) \times p(X_2 = 1) + p(X_1 = 1) \times p(X_2 = 0) \\ &= (1 - p)p + p(1 - p) = 2p(1 - p) = C_2^1 p^1 (1 - p)^{2-1} \\ p(X = 2) &= p(X_1 + X_2 = 2) = p(X_1 = 1 \text{ et } X_2 = 1) = p(X_1 = 1) \times p(X_2 = 1) = p^2 = C_2^2 p^2 (1 - p)^{2-2} \end{aligned}p(X=0)p(X=1)p(X=2)​=p(X1​=0)×p(X2​=0)=(1−p)(1−p)=(1−p)2=C20​p0(1−p)2=p(X1​+X2​=1)=p{(X1​=0 et X2​=1) ou (X1​=1 et X2​=0)}=p(X1​=0 et X2​=1)+p(X1​=1 et X2​=0)=p(X1​=0)×p(X2​=1)+p(X1​=1)×p(X2​=0)=(1−p)p+p(1−p)=2p(1−p)=C21​p1(1−p)2−1=p(X1​+X2​=2)=p(X1​=1 et X2​=1)=p(X1​=1)×p(X2​=1)=p2=C22​p2(1−p)2−2​

On a montré le point 2 pour n=2n = 2n=2. On suppose que l'hypothèse de récurrence est vraie jusqu'à nnn. Soit X=X1+X2+⋯+Xn+1:Ω→{0,1,…,n+1}X = X_1 + X_2 + \dots + X_{n+1} : \Omega \to \{0, 1, \dots, n+1\}X=X1​+X2​+⋯+Xn+1​:Ω→{0,1,…,n+1}. Soit k∈{0,1,2,…,n+1}k \in \{0, 1, 2, \dots, n+1\}k∈{0,1,2,…,n+1}.

p(X1+⋯+Xn+1=k)=p(X1+⋯+Xn=k et Xn+1=0)+p(X1+⋯+Xn=k−1 et Xn+1=1)=p(X1+⋯+Xn=k)×p(Xn+1=0)+p(X1+⋯+Xn=k−1)×p(Xn+1=1)=Cnkpk(1−p)n−k(1−p)+Cnk−1pk−1(1−p)n−k+1p=Cnkpk(1−p)n+1−k+Cnk−1pk(1−p)n+1−k=(Cnk+Cnk−1)pk(1−p)n+1−k=Cn+1kpk(1−p)n+1−k\begin{aligned} p(X_1 + \dots + X_{n+1} = k) &= p(X_1 + \dots + X_n = k \text{ et } X_{n+1} = 0) + p(X_1 + \dots + X_n = k - 1 \text{ et } X_{n+1} = 1) \\ &= p(X_1 + \dots + X_n = k) \times p(X_{n+1} = 0) + p(X_1 + \dots + X_n = k - 1) \times p(X_{n+1} = 1) \\ &= C_n^k p^k (1 - p)^{n-k}(1 - p) + C_n^{k-1} p^{k-1} (1 - p)^{n-k+1} p \\ &= C_n^k p^k (1 - p)^{n+1-k} + C_n^{k-1} p^k (1 - p)^{n+1-k} \\ &= (C_n^k + C_n^{k-1}) p^k (1 - p)^{n+1-k} = C_{n+1}^k p^k (1 - p)^{n+1-k} \end{aligned}p(X1​+⋯+Xn+1​=k)​=p(X1​+⋯+Xn​=k et Xn+1​=0)+p(X1​+⋯+Xn​=k−1 et Xn+1​=1)=p(X1​+⋯+Xn​=k)×p(Xn+1​=0)+p(X1​+⋯+Xn​=k−1)×p(Xn+1​=1)=Cnk​pk(1−p)n−k(1−p)+Cnk−1​pk−1(1−p)n−k+1p=Cnk​pk(1−p)n+1−k+Cnk−1​pk(1−p)n+1−k=(Cnk​+Cnk−1​)pk(1−p)n+1−k=Cn+1k​pk(1−p)n+1−k​

Montrons que Cnk+Cnk−1=Cn+1kC_n^k + C_n^{k-1} = C_{n+1}^kCnk​+Cnk−1​=Cn+1k​ :

Cnk+Cnk−1=n!k!(n−k)!+n!(k−1)!(n−(k−1))!=n!k!(n−k)!+n!(k−1)!(n+1−k)!=n!k!(n+1−k)![(n+1−k)+k]=n!k!(n+1−k)!(n+1)=(n+1)!k!(n+1−k)!=Cn+1k\begin{aligned} C_n^k + C_n^{k-1} &= \frac{n!}{k!(n-k)!} + \frac{n!}{(k-1)!(n-(k-1))!} = \frac{n!}{k!(n-k)!} + \frac{n!}{(k-1)!(n+1-k)!} \\ &= \frac{n!}{k!(n+1-k)!}[(n + 1 - k) + k] = \frac{n!}{k!(n+1-k)!}(n + 1) = \frac{(n+1)!}{k!(n+1-k)!} = C_{n+1}^k \end{aligned}Cnk​+Cnk−1​​=k!(n−k)!n!​+(k−1)!(n−(k−1))!n!​=k!(n−k)!n!​+(k−1)!(n+1−k)!n!​=k!(n+1−k)!n!​[(n+1−k)+k]=k!(n+1−k)!n!​(n+1)=k!(n+1−k)!(n+1)!​=Cn+1k​​

Théorème IX.4. Soit X=B(n,p)X = \mathcal{B}(n, p)X=B(n,p). On a :

E(X)=npV(X)=np(1−p)E(X) = np \qquad V(X) = np(1 - p)E(X)=npV(X)=np(1−p)

Démonstration. X=X1+⋯+Xn⇔E(X)=E(X1+⋯+Xn)=E(X1)+⋯+E(Xn)=npX = X_1 + \dots + X_n \Leftrightarrow E(X) = E(X_1 + \dots + X_n) = E(X_1) + \dots + E(X_n) = npX=X1​+⋯+Xn​⇔E(X)=E(X1​+⋯+Xn​)=E(X1​)+⋯+E(Xn​)=np.

V(X)=V(X1+⋯+Xn)=V(X1)+V(X2)+⋯+V(Xn)=np(1−p)V(X) = V(X_1 + \dots + X_n) = V(X_1) + V(X_2) + \dots + V(X_n) = np(1 - p)V(X)=V(X1​+⋯+Xn​)=V(X1​)+V(X2​)+⋯+V(Xn​)=np(1−p)
