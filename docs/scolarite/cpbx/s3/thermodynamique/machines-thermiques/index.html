Machines thermiques

Généralités​

Définition. Une machine thermodynamique est un système fonctionnant grâce à un fluide auquel on fait subir des transformations cycliques, au cours desquelles il y a échange d'énergie avec le milieu extérieur. Le milieu extérieur est constitué de nnn sources de chaleur échangeant de la chaleur avec le fluide, et d'un système mécanique échangeant du travail avec le fluide.

Classification​

Machine monotherme. C'est un système thermodynamique en contact avec une seule source. Thomson a démontré en 1852 que les moteurs monothermes n'existent pas.

Machines cycliques. L'état initial et l'état final sont confondus : ΔU=0\Delta U = 0ΔU=0 et ΔS=0\Delta S = 0ΔS=0. Il s'y produit des échanges de travail WWW et d'énergie QQQ. Sur un cycle, on a donc ΔU=W+Q=0\Delta U = W + Q = 0ΔU=W+Q=0. Deux cas sont possibles : soit un moteur (W<0W < 0W<0 et Q>0Q > 0Q>0), soit un récepteur (W>0W > 0W>0 et Q<0Q < 0Q<0).

Machines dithermes. C'est un système thermodynamique en contact avec une source chaude et une source froide.

Étude théorique : bilan d'énergie et d'entropie. L'énergie du système fermé est définie par

ΔU=W+Q\Delta U = W + QΔU=W+Q

Sur un cycle, ΔU=0\Delta U = 0ΔU=0. On note QcQ_cQc​ les échanges avec la source chaude à TcT_cTc​ et QfQ_fQf​ les échanges avec la source froide à TfT_fTf​. Le premier principe donne

W+Qc+Qf=0W + Q_c + Q_f = 0W+Qc​+Qf​=0

L'entropie du système fermé est définie par le second principe :

ΔS=Sech+Screˊeˊe\Delta S = S_{ech} + S_{créée}ΔS=Sech​+Screˊeˊe​

Le système échange de l'entropie avec les deux sources pendant ces échanges :

dSech=δQTsource⇒Sech=∫δQTsource=∫δQTc+∫δQTf=1Tc∫δQ+1Tf∫δQ=QcTc+QfTfdS_{ech} = \frac{\delta Q}{T_{source}} \Rightarrow S_{ech} = \int \frac{\delta Q}{T_{source}} = \int \frac{\delta Q}{T_c} + \int \frac{\delta Q}{T_f} = \frac{1}{T_c} \int \delta Q + \frac{1}{T_f} \int \delta Q = \frac{Q_c}{T_c} + \frac{Q_f}{T_f}dSech​=Tsource​δQ​⇒Sech​=∫Tsource​δQ​=∫Tc​δQ​+∫Tf​δQ​=Tc​1​∫δQ+Tf​1​∫δQ=Tc​Qc​​+Tf​Qf​​
ΔS=QcTc+QfTf+Screˊeˊe=0\Delta S = \frac{Q_c}{T_c} + \frac{Q_f}{T_f} + S_{créée} = 0ΔS=Tc​Qc​​+Tf​Qf​​+Screˊeˊe​=0

d'où l'inégalité de Clausius :

QcTc+QfTf≤0\frac{Q_c}{T_c} + \frac{Q_f}{T_f} \leq 0Tc​Qc​​+Tf​Qf​​≤0

On peut généraliser à NNN sources aux températures TiT_iTi​ : ∑i=1NQiTi≤0\displaystyle\sum_{i=1}^{N} \frac{Q_i}{T_i} \leq 0i=1∑N​Ti​Qi​​≤0. Dans le cas où N=1N = 1N=1, on retrouve qu'il n'existe pas de moteur monotherme :

Moteur ditherme​

Sens des transferts thermiques​

Le premier principe donne ΔU=W+Qc+Qf=0\Delta U = W + Q_c + Q_f = 0ΔU=W+Qc​+Qf​=0 (car la transformation est cyclique), ainsi

Qc+Qf=−WQ_c + Q_f = -WQc​+Qf​=−W

Or −W>0-W > 0−W>0 car c'est un moteur, donc Qc+Qf>0Q_c + Q_f > 0Qc​+Qf​>0.

Raisonnons par l'absurde et supposons Qc<0Q_c < 0Qc​<0. Alors

Qf>−Qc>0⇒QfTf>−QcTf>−QcTc⇒QfTf+QcTc>0\begin{aligned} Q_f &> -Q_c > 0 \\ \Rightarrow \frac{Q_f}{T_f} &> -\frac{Q_c}{T_f} > -\frac{Q_c}{T_c} \\ \Rightarrow \frac{Q_f}{T_f} + \frac{Q_c}{T_c} &> 0 \end{aligned}Qf​⇒Tf​Qf​​⇒Tf​Qf​​+Tc​Qc​​​>−Qc​>0>−Tf​Qc​​>−Tc​Qc​​>0​

La dernière ligne est impossible d'après le second principe (inégalité de Clausius). En conclusion, Qc>0Q_c > 0Qc​>0 et Qf≤−TfTc<0Q_f \leq -\dfrac{T_f}{T_c} < 0Qf​≤−Tc​Tf​​<0 : le moteur ditherme reçoit de la chaleur de la source chaude et en fournit à la source froide. Le schéma de principe du moteur ditherme est donc le suivant.

Efficacité et rendement : théorème de Carnot​

Définition. L'efficacité est le rapport de l'énergie utile sur l'énergie dépensée pour le fonctionnement :

e=utiledeˊpenseˊee = \frac{\text{utile}}{\text{dépensée}}e=deˊpenseˊeutile​

e=−WQc=1+QfQc<1car{Qf<0Qc>0e = \frac{-W}{Q_c} = 1 + \frac{Q_f}{Q_c} < 1 \quad \text{car} \quad \begin{cases} Q_f < 0 \\ Q_c > 0 \end{cases}e=Qc​−W​=1+Qc​Qf​​<1car{Qf​<0Qc​>0​

De plus :

QcTc+QfTf≤0⇒ QfTf≤−QcTc⇒ QfQc≤−TfTccar Qc>0\begin{aligned} &\frac{Q_c}{T_c} + \frac{Q_f}{T_f} \leq 0 \\ \Rightarrow\ &\frac{Q_f}{T_f} \leq -\frac{Q_c}{T_c} \\ \Rightarrow\ &\frac{Q_f}{Q_c} \leq -\frac{T_f}{T_c} \quad \text{car } Q_c > 0 \end{aligned}⇒ ⇒ ​Tc​Qc​​+Tf​Qf​​≤0Tf​Qf​​≤−Tc​Qc​​Qc​Qf​​≤−Tc​Tf​​car Qc​>0​

e≤1−TfTce \leq 1 - \frac{T_f}{T_c}e≤1−Tc​Tf​​

Il y a égalité si le cycle est réversible. On appelle cette efficacité théorique maximale l'efficacité de Carnot :

ec=1−TfTce_c = 1 - \frac{T_f}{T_c}ec​=1−Tc​Tf​​

D'où le théorème de Carnot : tous les moteurs dithermes réversibles ont le même rendement, qui ne dépend que des températures des sources. Le rendement des moteurs non réversibles est inférieur à celui des moteurs réversibles.

Récepteurs dithermes​

Un récepteur ditherme est caractérisé par W>0W > 0W>0, Qc<0Q_c < 0Qc​<0 et Qf>0Q_f > 0Qf​>0. Le principe est d'inverser le sens naturel du transfert de chaleur en fournissant du travail au récepteur.

Réfrigérateur et climatiseur​

Le but est de refroidir la source froide TfT_fTf​. L'efficacité se définit par e=utiledeˊpenseˊe = \dfrac{\text{utile}}{\text{dépensé}}e=deˊpenseˊutile​ ; dans le cas d'un réfrigérateur :

e=QfWe = \frac{Q_f}{W}e=WQf​​

D'après le premier principe, W=−Qf−QcW = -Q_f - Q_cW=−Qf​−Qc​, ainsi

e=Qf−Qf−Qc=−11+QcQfe = \frac{Q_f}{-Q_f - Q_c} = \frac{-1}{1 + \dfrac{Q_c}{Q_f}}e=−Qf​−Qc​Qf​​=1+Qf​Qc​​−1​

Pompe à chaleur​

Le but est de chauffer la source chaude TcT_cTc​ (piscine, habitation…). Dans le cas d'une pompe à chaleur :

e=−QcWe = \frac{-Q_c}{W}e=W−Qc​​

ec=11−TfTce_c = \frac{1}{1 - \dfrac{T_f}{T_c}}ec​=1−Tc​Tf​​1​

Cycle de Carnot​

Théorème de Carnot​

L'efficacité d'une machine ditherme cyclique réelle est inférieure ou égale à celle d'une machine ditherme cyclique réversible fonctionnant avec les deux mêmes sources. Cette machine est appelée machine de Carnot.

Cycle de Carnot​

Un cycle de Carnot est un cycle ditherme réversible. La seule solution est de combiner deux isentropiques et deux isothermes.

Remarque sur le sens de parcours. On a δW=−pext dV\delta W = -p_{ext}\,dVδW=−pext​dV ; si la transformation est réversible, elle est quasi statique et P=PextP = P_{ext}P=Pext​. Donc, sur un cycle :

W=−∮P dV=−Aire du cycle dans (P,V)W = -\oint P\,dV = -\text{Aire du cycle dans } (P, V)W=−∮PdV=−Aire du cycle dans (P,V)

Si l'aire est positive et le travail négatif, la machine est un moteur. Si l'aire est négative et le travail positif, c'est un récepteur.

Bilan. Sens antihoraire : l'aire est négative, le travail positif, donc récepteur. Sens horaire : l'aire est positive, le travail négatif, donc moteur.

Exemples de machines réelles​

Le moteur à explosion (ou à combustion interne)​

Description du cycle. C'est un cycle à 4 temps. Il entraîne un piston mobile et deux soupapes qui permettent l'admission de l'essence et l'évacuation des gaz.

Remarque. Le cycle est parcouru dans le sens horaire : c'est donc un moteur.

Modélisation. On étudie le système formé de l'air, du carburant et des gaz d'échappement, que l'on assimile à un gaz parfait avec γ=1,4\gamma = 1{,}4γ=1,4. On applique une source chaude à TcT_cTc​ en contact avec le système : Qc=QCDQ_c = Q_{CD}Qc​=QCD​.

  • L'admission est isobare et isotherme (TA=TBT_A = T_BTA​=TB​).
  • La compression et la détente sont adiabatiques et réversibles : ce sont des isentropiques.
  • L'explosion est isochore.

Le cycle est bien parcouru dans le sens horaire avec un travail négatif : c'est un moteur.

Un récepteur : le réfrigérateur​

Principe.

W+Qc+Qf=0W + Q_c + Q_f = 0W+Qc​+Qf​=0

Un fluide (l'isobutane C4H10C_4H_{10}C4​H10​, 20 000 fois moins nocif que le fréon CF2Cl2CF_2Cl_2CF2​Cl2​) subit un cycle (système fermé) avec possibilité de changement d'état.

Cycle. Il comporte quatre étapes : une compression suivie d'un changement d'état dans le condenseur, qui joue le rôle de source chaude, puis une détente et un changement d'état dans l'évaporateur, qui joue le rôle de source froide.
