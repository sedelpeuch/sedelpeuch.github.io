Espaces vectoriels euclidiens

Produit scalaire​

Soit EEE un espace vectoriel.

Définition 1. Un produit scalaire sur EEE est une application bilinéaire symétrique définie positive. Cela veut dire que ϕ:E×E→K\phi : E \times E \to \mathbb{K}ϕ:E×E→K est un produit scalaire lorsque :

  • ϕ(x+λx′,y)=ϕ(x,y)+λϕ(x′,y)\phi(x + \lambda x', y) = \phi(x, y) + \lambda \phi(x', y)ϕ(x+λx′,y)=ϕ(x,y)+λϕ(x′,y) et ϕ(x,y+λy′)=ϕ(x,y)+λϕ(x,y′)\phi(x, y + \lambda y') = \phi(x, y) + \lambda \phi(x, y')ϕ(x,y+λy′)=ϕ(x,y)+λϕ(x,y′) : bilinéaire ;
  • ϕ(x,y)=ϕ(y,x)\phi(x, y) = \phi(y, x)ϕ(x,y)=ϕ(y,x) : symétrique ;
  • (ϕ(x,x)≥0)(\phi(x, x) \geq 0)(ϕ(x,x)≥0) et (ϕ(x,x)=0⇔x=0)(\phi(x, x) = 0 \Leftrightarrow x = 0)(ϕ(x,x)=0⇔x=0) : définie positive.

Définition 2. On appelle espace euclidien (e.v.e) un espace vectoriel de dimension finie muni d'un produit scalaire. On parle d'espace vectoriel préhilbertien si dim⁡(E)=+∞\dim(E) = +\inftydim(E)=+∞.

Exemples fondamentaux.

  1. E=RnE = \mathbb{R}^nE=Rn et ϕ(x,y)=∑i=1nxiyi\phi(x, y) = \displaystyle\sum_{i=1}^{n} x_i y_iϕ(x,y)=i=1∑n​xi​yi​. Vérifions que c'est un produit scalaire.
