Généralités sur les suites récurrentes​

Pour un+1=f(un)u_{n+1} = f(u_n)un+1​=f(un​). Déterminer le domaine de définition de fff : Df⊂RD_f \subset \mathbb{R}Df​⊂R.

  • Si fff est croissante et u0≥u1u_0 \geq u_1u0​≥u1​, alors f(u0)≥f(u1)f(u_0) \geq f(u_1)f(u0​)≥f(u1​), c'est-à-dire u1≥u2u_1 \geq u_2u1​≥u2​, et par récurrence un≥un+1u_n \geq u_{n+1}un​≥un+1​. La suite est donc décroissante.
  • Si fff est décroissante :
    • si u0≤u1u_0 \leq u_1u0​≤u1​, alors f(u0)≥f(u1)f(u_0) \geq f(u_1)f(u0​)≥f(u1​), c'est-à-dire u1≥u2u_1 \geq u_2u1​≥u2​, etc. : u2n≤u2n+1u_{2n} \leq u_{2n+1}u2n​≤u2n+1​ et u2n+1≥u2n+2u_{2n+1} \geq u_{2n+2}u2n+1​≥u2n+2​.     • si u0≥u1u_0 \geq u_1u0​≥u1​, alors f(u0)≤f(u1)f(u_0) \leq f(u_1)f(u0​)≤f(u1​), c'est-à-dire u1≤u2u_1 \leq u_2u1​≤u2​, d'où u2n≥u2n+1u_{2n} \geq u_{2n+1}u2n​≥u2n+1​ et u2n+1≤u2n+2u_{2n+1} \leq u_{2n+2}u2n+1​≤u2n+2​.   • Si u0u_0u0​ est un point fixe de fff (c'est-à-dire f(u0)=u0f(u_0) = u_0f(u0​)=u0​), alors la suite est constante :
    • si fff est continue et unu_nun​ converge, un→xu_n \to xun​→x, alors f(un)→f(x)f(u_n) \to f(x)f(un​)→f(x) (continuité), ainsi un+1→xu_{n+1} \to xun+1​→x et donc f(x)=xf(x) = xf(x)=x : la limite fait partie des points fixes ;
