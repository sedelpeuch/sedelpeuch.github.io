Divisibilité dans Z

Une construction de Z\mathbb{Z}Z, ensemble des entiers relatifs​

Si n∈N∗n \in \mathbb{N}^*n∈N∗, l'équation n+x=0n + x = 0n+x=0 n'a pas de solution dans N\mathbb{N}N. On est donc conduit à construire un ensemble de nombres plus vaste que N\mathbb{N}N pour y trouver une solution.

Par ailleurs, l'échange commercial primitif "je reçois nnn et je donne mmm" peut se modéliser sous la forme du couple (n,m)(n, m)(n,m), élément de N2\mathbb{N}^2N2, au format (quantité reçue, quantité donnée). L'échange (n,m)(n, m)(n,m) a le même bilan (profit ou perte) que l'échange (n′,m′)(n', m')(n′,m′) lorsque, pour un même individu, la succession des échanges (n,m)(n, m)(n,m) puis (m′,n′)(m', n')(m′,n′) a un bilan nul, c'est-à-dire lorsque la quantité n+m′n + m'n+m′ reçue est égale à la quantité m+n′m + n'm+n′ donnée.

Dans N2\mathbb{N}^2N2, on considère la relation R\mathcal{R}R définie par :

∀((n,m),(n′,m′))∈(N2)2,(n,m)R(n′,m′)⇔n+m′=m+n′\forall ((n, m), (n', m')) \in (\mathbb{N}^2)^2, (n, m)\mathcal{R}(n', m') \Leftrightarrow n + m' = m + n'∀((n,m),(n′,m′))∈(N2)2,(n,m)R(n′,m′)⇔n+m′=m+n′

On montre que R\mathcal{R}R est une relation d'équivalence (R-S-T) dans N2\mathbb{N}^2N2.

Pour tout couple (n,m)(n, m)(n,m) de N2\mathbb{N}^2N2, sa classe d'équivalence est n,m‾={(n′,m′)∈N2/(n′,m′)R(n,m)}\overline{n, m} = \{(n', m') \in \mathbb{N}^2 / (n', m')\mathcal{R}(n, m)\}n,m​={(n′,m′)∈N2/(n′,m′)R(n,m)}.

L'ensemble de ces classes d'équivalence, dit ensemble quotient N2/R\mathbb{N}^2/\mathcal{R}N2/R, est noté Z\mathbb{Z}Z.

∀n∈N\forall n \in \mathbb{N}∀n∈N, nous noterons n,0‾\overline{n, 0}n,0​ par +n+n+n et 0,n‾\overline{0, n}0,n​ par −n-n−n ; 0,0‾\overline{0, 0}0,0​ est noté 0.

  • +++ est associative.

  • Tout élément de Z\mathbb{Z}Z admet un symétrique pour +++ (opposé).

  • ×\times× est associative.
