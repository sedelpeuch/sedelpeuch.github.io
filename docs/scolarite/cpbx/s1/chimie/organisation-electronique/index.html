Organisation des électrons dans l'atome

Ce chapitre de structure de la matière aborde les systèmes hydrogénoïdes puis les atomes polyélectroniques.

Les systèmes hydrogénoïdes​

Fonction d'onde, probabilité de présence​

Modèle actuel de la mécanique quantique :

  • dualité onde/corpuscule (De Broglie) : λ=hm.ν=hp\lambda = \dfrac{h}{m.\nu} = \dfrac{h}{p}λ=m.νh​=ph​ ;
  • principe d'indétermination (Heisenberg) : Δx.Δp≥h4π\Delta x . \Delta p \geq \dfrac{h}{4\pi}Δx.Δp≥4πh​ ;
  • le concept de trajectoire n'existe pas en mécanique quantique.

Le comportement ondulatoire est décrit par une fonction d'onde (équation de Schrödinger) :

  • pour un système hydrogénoïde, Ψ2=dPdV\Psi^2 = \dfrac{dP}{dV}Ψ2=dVdP​ (dPdPdP est la probabilité de trouver la particule dans un volume élémentaire dVdVdV) ;
  • P=∫VΨ2.dV=1P = \displaystyle\int_{V} \Psi^2 . dV = 1P=∫V​Ψ2.dV=1 : la fonction d'onde est normalisée (voir exemple) ;
  • le carré de la fonction d'onde représente la densité de probabilité de présence simultanée des électrons dans l'espace (voir équation de Schrödinger).

Nombres quantiques​

Les orbitales atomiques (OA) définissent des volumes dans lesquels un électron a une probabilité de se trouver ; elles dépendent de 3 nombres :

  • nnn : nombre quantique principal (n>0n > 0n>0) ;
  • lll : nombre quantique azimutal (0≤l<n0 \leq l < n0≤l<n) ;
  • mmm : nombre quantique magnétique (−l≤m≤+l-l \leq m \leq +l−l≤m≤+l).

Expression des orbitales​

Les orbitales atomiques dépendent de 3 coordonnées sphériques (r,θ,ϕ)(r, \theta, \phi)(r,θ,ϕ). On a donc :

x=rsin⁡θcos⁡ϕ  ;y=rsin⁡θsin⁡ϕ  ;z=rcos⁡θx = r \sin\theta \cos\phi \; ; \quad y = r \sin\theta \sin\phi \; ; \quad z = r \cos\thetax=rsinθcosϕ;y=rsinθsinϕ;z=rcosθ

Spin de l'électron​

Quatrième nombre quantique, le nombre quantique de spin msm_sms​ est lié à la rotation de l'électron sur lui-même. Il peut prendre 2 valeurs :

α=12β=−12\alpha = \frac{1}{2} \qquad \beta = -\frac{1}{2}α=21​β=−21​

Énergie des OA​

L'état d'un atome est défini par (n,l,m,ms)(n, l, m, m_s)(n,l,m,ms​) ; chaque état est associé à une énergie :

En=−mee4Z28ϵ02h2n2=−13,6Z2n2E_n = \frac{-m_e e^4 Z^2}{8 \epsilon_0^2 h^2 n^2} = -13{,}6 \frac{Z^2}{n^2}En​=8ϵ02​h2n2−me​e4Z2​=−13,6n2Z2​

Toutes les OA d'une même couche (nnn) ont la même énergie : elles sont dégénérées. Ainsi le degré de dégénérescence est g=n2g = n^2g=n2.

L'occupation de l'OA par un électron est schématisée par une flèche dépendant du spin.

Les atomes polyélectroniques​

Énergies des OA​

L'équation de Schrödinger est insoluble de manière exacte pour les atomes polyélectroniques. L'énergie d'une OA dépend donc des nombres quantiques nnn et lll.

Configuration électronique des éléments​

Principe d'exclusion de Pauli.

  • Dans un atome donné, deux électrons ne peuvent être caractérisés par 4 nombres quantiques identiques.
  • Une OA peut être occupée par au plus 2 électrons.
  • Si 2 électrons occupent une même OA (nnn, lll, mmm identiques), alors leurs spins sont différents.

Règle de Klechkovski.

  • Dans l'état fondamental, les électrons occupent les OA de plus basses énergies.
  • Si n+l=n′+l′n + l = n' + l'n+l=n′+l′, alors l'OA dont le nombre quantique nnn est inférieur a une énergie inférieure.

Règle de Hund.

  • Dans une même sous-couche, les électrons occupent un maximum d'OA.
  • Le spin total doit être maximal.

Cœur et valence​

  • Électrons de cœur : électrons des couches internes, ils ne participent pas à la réactivité chimique de l'atome.
  • Électrons de valence : électrons de la couche de plus grand nnn et électrons de la dernière sous-couche non pleine.
