Hybridation des orbitales atomiques

Modèle des orbitales atomiques hybrides​

Définition d'une OA hybride​

  • Les orbitales atomiques sont un outil de description d'un atome isolé : elles reflètent la symétrie sphérique de l'atome.
  • Dans une molécule, les orbitales se déforment et forment donc des hybrides.
  • Les orbitales hybrides sont construites à partir du mélange des orbitales atomiques de l'atome isolé.

Hybridation sp​

  • Mélange d'OA s et d'OA p.
  • 2 hybrides orientées à 180°.
  • Molécule de type AX2AX_2AX2​ ou AXEAXEAXE.

Hybridation sp²​

Molécule du type AX3AX_3AX3​, AX2EAX_2EAX2​E ou AXE2AXE_2AXE2​.

Hybridation sp³​

Molécule du type AX4AX_4AX4​, AX3EAX_3EAX3​E ou AX2E2AX_2E_2AX2​E2​.

Hybridation sp³d​

Molécule du type AX5AX_5AX5​, AX4EAX_4EAX4​E, AX3E2AX_3E_2AX3​E2​, etc.

Hybridation sp³d²​

Molécule du type AX6AX_6AX6​, AX5EAX_5EAX5​E ou AX4E2AX_4E_2AX4​E2​.

Liaisons doubles et triples​

Deux types de liaisons : σ\sigmaσ et π\piπ.
