Formules de Taylor

Étudier une fonction fff peut être "difficile". L'idée des formules de Taylor est d'approximer une fonction fff avec des fonctions polynomiales. Si fff est assez régulière en un point, on pourra le faire localement. Pour formaliser l'idée, on peut définir la notion suivante.

Définition 5.1. Soit III un intervalle (ouvert) de R\mathbb{R}R, x0∈Ix_0 \in Ix0​∈I et f:I→RNf : I \to \mathbb{R}^Nf:I→RN qui est dérivable nnn fois en x0x_0x0​. Alors le polynôme de fff de degré nnn autour de x0x_0x0​ est

Pf,n,x0=∑k=0nf(k)(x0)k!(x−x0)kP_{f, n, x_0} = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!} (x - x_0)^kPf,n,x0​​=k=0∑n​k!f(k)(x0​)​(x−x0​)k

Par exemple, Pf,0,x0=f(x0)P_{f, 0, x_0} = f(x_0)Pf,0,x0​​=f(x0​) ; si fff est dérivable une fois

Pf,1,x0=f(x0)+f′(x0)(x−x0)P_{f, 1, x_0} = f(x_0) + f'(x_0)(x - x_0)Pf,1,x0​​=f(x0​)+f′(x0​)(x−x0​)

Exemple 5.1 (Graphique). Soit f(x)=exf(x) = e^xf(x)=ex.
