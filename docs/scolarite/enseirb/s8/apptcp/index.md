---

Le cours d'applications TCP/IP porte sur les couches hautes des réseaux. Les notes partent des couches session, présentation et application du modèle OSI, passent par la résolution de noms avec le DNS, puis par HTTP et le courrier électronique (SMTP, POP3), et se terminent par le routage IP et l'algorithme de Dijkstra. Le projet, mené à cinq, simule un aquarium en réseau selon le modèle client-serveur : un serveur en C et un client Java communiquent en TCP.
