PL - Cours 2

On dispose d'un formalisme pour modéliser des problèmes réels : la programmation linéaire. On a appris à résoudre le problème à la main en deux dimensions. Intuition pour résoudre en dimension supérieure : se déplacer de sommet en sommet du polyèdre convexe formé par les contraintes linéaires.

Résumé : forme standard, points extrêmes et bases​

Les variables supplémentaires sis_isi​ sont appelées variables d'écart. Chaque variable d'écart est associée à une contrainte.

forme standardmax⁡z=∑i=1nciximax⁡z=∑i=1ncixi∑i=1naijxi≤bj∑i=1naijxi+sj=bjxi≥0xi≥0sj≥0\begin{align*} && \text{forme standard} \\ \max z = \sum \limits_{i=1}^n c_i x_i && \max z = \sum \limits_{i=1}^n c_i x_i \\ \sum \limits_{i=1}^n a_{ij} x_i \leq b_j && \sum \limits_{i=1}^n a_{ij} x_i + s_j = b_j \\ x_i \geq 0 && x_i \geq 0 \\ && s_j \geq 0 \end{align*}maxz=i=1∑n​ci​xi​i=1∑n​aij​xi​≤bj​xi​≥0​​forme standardmaxz=i=1∑n​ci​xi​i=1∑n​aij​xi​+sj​=bj​xi​≥0sj​≥0​

On dispose d'un problème linéaire à n+mn+mn+m variables et mmm contraintes. Si on annule nnn variables, on obtient un système de mmm équations à mmm inconnues. Si la matrice associée est de rang mmm (base), le système admet une solution unique. Pour résoudre le problème obtenu : pivot de Gauss.

Une solution de base réalisable correspond à un point extrême du polyèdre des contraintes. Pour calculer les valeurs des variables pour ces points on utilise le pivotage. Il reste à voir comment trouver une première base réalisable et comment passer d'une base réalisable à une autre.

Description formelle de la méthode​

Problème linéaire avec les variables d'écart et la variable objectif :

z=∑j=1ncjxjxn+i=bi−∑j=1naijxj\begin{align*} z&=\sum \limits_{j=1}^n c_j x_j \\ x_{n+i}&=b_i-\sum \limits_{j=1}^n a_{ij} x_j \end{align*}zxn+i​​=j=1∑n​cj​xj​=bi​−j=1∑n​aij​xj​​

Dictionnaires​

À chaque itération, la solution courante est associée à un système d'équations qui la définit :

z=z‾+∑j∈Nc‾jxjxi=b‾i−∑j∈Na‾ijxj\begin{align*} z &= \overline{z} + \sum \limits_{j \in \mathcal{N}} \overline{c}_j x_j \\ x_i &= \overline{b}_i - \sum \limits_{j \in \mathcal{N}} \overline{a}_{ij} x_j \end{align*}zxi​​=z+j∈N∑​cj​xj​=bi​−j∈N∑​aij​xj​​

Ce système s'appelle un dictionnaire. Les variables de gauche sont appelées variables de base et notées xB∈R+mx_\mathcal{B} \in \mathbb{R}_+^mxB​∈R+m​. L'ensemble des variables en base est appelé base. B\mathcal{B}B représente les indices des variables en base. Les variables qui ne sont pas dans la base sont appelées variables hors base et notées xN∈R+nx_\mathcal{N} \in \mathbb{R}_+^nxN​∈R+n​. N\mathcal{N}N représente l'ensemble des indices des variables hors-base.

  • B\mathcal{B}B et N\mathcal{N}N forment une partition de l'ensemble des indices
  • Chaque dictionnaire définit une solution de base que l'on obtient en posant xN=0x_\mathcal{N}=0xN​=0
  • Un dictionnaire est réalisable si la solution de base associée est telle que xB≥0x_\mathcal{B} \geq 0xB​≥0

Dictionnaire initial​

  • La base initiale est formée des variables d'écart xn+1,…,xn+mx_{n+1},\ldots,x_{n+m}xn+1​,…,xn+m​, c'est-à-dire B={n+1,…,n+m}\mathcal{B}=\{n+1,\ldots,n+m\}B={n+1,…,n+m}
  • Les variables hors-base sont les variables initiales du problème, N={1,…,n}\mathcal{N}=\{1,\ldots,n\}N={1,…,n}
  • Attention : la base initiale peut ne pas être réalisable. On verra plus tard ce qu'il faut faire dans ce cas.

Itération (pivotage)​

  • À chaque itération de l'algorithme du simplexe, une variable hors-base va entrer dans la base, tandis qu'une variable en base sortira de la base, c'est le pivotage
  • Cette opération revient à se déplacer d'un point extrême à un point extrême voisin le long d'une arête du polyèdre

Choix de la variable entrante​

Les coefficients c‾j,j∈N\overline{c}_j,j\in \mathcal{N}cj​,j∈N sont appelés les coûts réduits. Ils représentent l'impact de l'augmentation d'une variable sur l'objectif. La solution de base est optimale si et seulement si tous les coûts réduits sont négatifs ou nuls : c‾j≤0\overline{c}_j \leq 0cj​≤0 (la condition est suffisante ; elle est aussi nécessaire en l'absence de dégénérescence).

On choisit une variable xkx_kxk​ de N\mathcal{N}N dont le coût réduit c‾k\overline{c}_kck​ est strictement positif. Il peut y avoir plusieurs variables candidates pour entrer en base. La règle de pivotage permet de choisir laquelle va entrer en base.

Choix de la variable sortante​

Supposons que la variable xkx_kxk​ est choisie pour entrer en base. Le vecteur formé par les coefficients a‾i,k,i∈B\overline{a}_{i,k},i \in \mathcal{B}ai,k​,i∈B indique l'impact sur les variables en base de l'augmentation de la variable xkx_kxk​.

  • Si a‾i,k≤0\overline{a}_{i,k} \leq 0ai,k​≤0, augmenter xkx_kxk​ ne fait pas diminuer xix_ixi​ (augmentation ou stagnation) ;

  • si a‾i,k>0\overline{a}_{i,k} > 0ai,k​>0, augmenter xkx_kxk​ entraîne une diminution de xix_ixi​ : il faut faire attention à la positivité de xix_ixi​ :

    xi=b‾i−a‾i,kxk≥0⇒xk≤b‾ia‾i,kx_i = \overline{b}_i - \overline{a}_{i,k} x_k \geq 0 \Rightarrow x_k \leq \dfrac{\overline{b}_i}{\overline{a}_{i,k}}xi​=bi​−ai,k​xk​≥0⇒xk​≤ai,k​bi​​

La variable qui sort de la base est la première variable à s'annuler lorsque xkx_kxk​ (la variable entrante) augmente :

Choisir  s∈B  tel que  s=argmin⁡i∈B{b‾ia‾i,k:a‾i,k>0}\text{Choisir} \; s \in \mathcal{B} \; \text{tel que} \; s = \operatorname{argmin}_{i \in \mathcal{B}} \left\{\dfrac{\overline{b}_i}{\overline{a}_{i,k}} : \overline{a}_{i,k} > 0\right\}Choisirs∈Btel ques=argmini∈B​{ai,k​bi​​:ai,k​>0}

Il peut y avoir plusieurs variables candidates pour sortir de la base. Si c'est le cas, la base suivante sera dégénérée.

Le problème peut être non borné : si a‾i,k≤0\overline{a}_{i,k} \leq 0ai,k​≤0 pour tout i∈Bi \in \mathcal{B}i∈B, il n'y a pas de candidat pour sortir de la base et le problème est non borné.

Pivotage​

Mise à jour du système :

  • on entre la variable xkx_kxk​ en base et on sort xsx_sxs​ ;
  • on élimine xkx_kxk​ de l'expression de zzz ;
  • on élimine xkx_kxk​ de l'expression des xix_ixi​ (i∈B,i≠s)(i \in \mathcal{B}, i \neq s)(i∈B,i=s).

Il reste à reconstruire le système d'équations ci-dessous pour la nouvelle base : c'est le pivotage.

z=z‾+∑j∈N\{k}c‾jxj+c‾kxkxi=b‾i−∑j∈N\{k}a‾i,jxj−a‾i,kxkxs=b‾s−∑j∈N\{k}a‾s,jxj−a‾s,kxk\begin{align*} z&=\overline{z}+\sum \limits_{j \in \mathcal{N}\backslash\{k\}} \overline{c}_j x_j + \overline{c}_k x_k\\ x_i&=\overline{b}_i-\sum \limits_{j \in \mathcal{N}\backslash\{k\}} \overline{a}_{i,j} x_j - \overline{a}_{i,k}x_k \\ x_s&=\overline{b}_s - \sum \limits_{j \in \mathcal{N}\backslash\{k\}} \overline{a}_{s,j}x_j - \overline{a}_{s,k}x_k \end{align*}zxi​xs​​=z+j∈N\{k}∑​cj​xj​+ck​xk​=bi​−j∈N\{k}∑​ai,j​xj​−ai,k​xk​=bs​−j∈N\{k}∑​as,j​xj​−as,k​xk​​

On entre la variable xkx_kxk​ en base et on sort xsx_sxs​. On divise l'équation de xsx_sxs​ par a‾s,k\overline{a}_{s,k}as,k​ pour ramener le coefficient de xkx_kxk​ à 1. On élimine xkx_kxk​ de l'expression de zzz. On élimine xkx_kxk​ de l'expression des xix_ixi​.

Remarques​

  • On remarque que le type de la variable (décision ou écart) n'est pas pris en compte lors du pivotage
  • Tenter de faire sortir les variables d'écart pour faire entrer les variables initiales n'est pas une bonne stratégie
  • Seuls les coûts réduits doivent être pris en compte
  • On s'arrête lorsque tous les coûts réduits sont négatifs ou nuls

Phase 1​

Cette phase permet de trouver une solution de base réalisable initiale lorsque la base donnée par les variables d'écart n'est pas réalisable.

D'où vient le problème ?​

∑jaijxj≤bi  avec  bi<0\sum \limits_j a_{ij} x_j \leq b_i \; \text{avec} \; b_i < 0j∑​aij​xj​≤bi​avecbi​<0

Après l'ajout de la variable d'écart et écriture sous forme de dictionnaire, on obtient xn+i=bi−∑jaijxjx_{n+i} = b_i - \sum_j a_{ij} x_jxn+i​=bi​−∑j​aij​xj​. Comme bi<0b_i<0bi​<0 la solution de base n'est pas réalisable.

Calculer une solution initiale​

  1. Pour chaque contrainte iii telle que bi<0b_i<0bi​<0, on ajoute une variable artificielle xn+i′x'_{n+i}xn+i′​ avec un coefficient de -1 en plus de la variable d'écart ∑jaijxj+xn+i−xn+i′=bi\sum_j a_{ij} x_j + x_{n+i} - x'_{n+i} = b_i∑j​aij​xj​+xn+i​−xn+i′​=bi​
  2. On crée un objectif artificiel max⁡∑i:bi<0−xn+i′\max \sum \limits_{i:b_i<0} - x'_{n+i}maxi:bi​<0∑​−xn+i′​
  3. Une base initiale pour le problème artificiel est obtenue avec les variables artificielles des contraintes avec bi<0b_i<0bi​<0 et les variables d'écarts des contraintes avec bi≥0b_i\geq 0bi​≥0
  4. On résout le problème avec l'algorithme du simplexe à partir de cette solution

Résultat de la phase 1​

À la fin de cette résolution :

  • s'il existe au moins un iii tel que xn+i′>0x'_{n+i} > 0xn+i′​>0, alors les variables artificielles sont nécessaires pour avoir une solution réalisable : le problème initial est irréalisable ;
  • si xn+i′=0x'_{n+i}=0xn+i′​=0 pour tout iii tel que bi<0b_i<0bi​<0, les variables artificielles sont nulles (si certaines restent en base à la valeur 0, on les fait sortir par pivotage). On a une solution de base réalisable pour le problème initial donnée par la base optimale de la Phase I
  1. Supprimer les variables artificielles
  2. Reprendre l'objectif initial
  3. Utiliser l'algorithme du simplexe avec la solution initiale trouvée

Dégénérescence​

Quand plusieurs variables sont candidates pour sortir de la base, la nouvelle solution de base aura une (ou plusieurs) variables de base prenant la valeur 0. On dit alors que la solution de base est dégénérée

Solutions optimales multiples​

Il peut arriver que, dans le dictionnaire optimal, des variables hors base possèdent des coûts réduits nuls : c‾i=0,  pour  i∈N\overline{c}_i = 0, \; \text{pour} \; i \in \mathcal{N}ci​=0,pouri∈N. En effectuant une itération supplémentaire du simplexe et en faisant entrer en base une variable xix_ixi​ telle que c‾i=0\overline{c}_i=0ci​=0, on obtient une nouvelle solution optimale de base (avec le même objectif). Si x1∗x_1^\astx1∗​ et x2∗x_2^\astx2∗​ sont deux solutions optimales, alors toute solution obtenue par une combinaison convexe de x1∗x_1^\astx1∗​ et x2∗x_2^\astx2∗​, x=αx1∗+(1−α)x2∗x=\alpha x_1^\ast + (1-\alpha)x_2^\astx=αx1∗​+(1−α)x2∗​ avec α∈[0,1]\alpha \in [0,1]α∈[0,1], est également une solution optimale.

Terminaison​

En cas de dégénérescence, l'algorithme peut revenir sur une solution de base déjà visitée (cycle). En pratique néanmoins, cela se passe rarement. Il existe des règles de pivotage limitant les risques de cycle.

  • règle du plus petit indice (règle de Bland), qui garantit la terminaison ;
  • perturbation des données : ajouter aux membres de droite des contraintes des ε\varepsilonε suffisamment petits.
