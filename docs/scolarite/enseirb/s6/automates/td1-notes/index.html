Automates finis et applications - TD1

Langages et automates finis​

Exercice 1​

Pour chaque langage ci-dessous sur l'alphabet {a,b}\{a,b\}{a,b}, donnez un automate fini déterministe qui l'accepte.

Le nombre de aaa est un multiple de 4.

Un nombre pair de aaa et impair de bbb.

Tout symbole aaa est précédé et suivi d'au moins un symbole bbb.

Remarque : dans cet automate, q0q_0q0​ n'est pas accepteur ; si l'on considère que le mot vide appartient au langage (il ne contient aucun aaa), il faut aussi rendre q0q_0q0​ accepteur.

Exercice 2​

Pour chaque langage ci-dessous sur l'alphabet binaire {0,1}\{0,1\}{0,1}, donnez un automate fini déterministe qui l'accepte.

Les entiers pairs.

Les entiers multiples de 3 (l'état qrq_rqr​ mémorise le reste rrr de la division par 3 du préfixe lu ; lire le bit bbb fait passer de rrr à (2r+b) mod 3(2r+b) \bmod 3(2r+b)mod3).

Exercice 3​

Pour chaque langage ci-dessous sur l'alphabet {a,b,c}\{a,b,c\}{a,b,c}, donnez un automate fini non déterministe qui l'accepte.

Les mots qui se terminent par aaaaaa.

Les mots dont la dernière lettre apparaît précédemment dans le mot.

Les mots dont la dernière lettre n'apparaît pas précédemment dans le mot (pas de schéma dans ces notes).

Exercice 5​

L'idée est de retirer le statut initial des deux états initiaux et de créer un nouvel état initial qui mène aux deux anciens.

Remarque : si l'objectif est de conserver le langage accepté, les transitions issues du nouvel état doivent être des transitions ϵ\epsilonϵ (ou bien le nouvel état doit reprendre les transitions sortantes des anciens états initiaux). Avec des transitions étiquetées aaa et bbb comme sur le schéma, chaque mot accepté est précédé d'une lettre supplémentaire.
