Mathématiques pour la robotique

À partir d'une position initiale, le robot tourne de θ\thetaθ puis avance de ttt puis tourne de α\alphaα puis avance de ddd. Donner son positionnement dans le repère (x,y,θ)(x,y,\theta)(x,y,θ).

  • Le robot tourne de θ\thetaθ puis avance de ttt. Dans le repère ΩO=(O,i⃗,j⃗)\Omega_O = (O, \vec{i}, \vec{j})ΩO​=(O,i,j​) :
T⃗ΩO=(uv)=t.(cos⁡θsin⁡θ)\vec{T}_{\Omega_O} = \begin{pmatrix} u\\ v \end{pmatrix} = t. \begin{pmatrix} \cos{\theta} \\ \sin{\theta} \end{pmatrix}TΩO​​=(uv​)=t.(cosθsinθ​)
  • Puis, le robot tourne de α\alphaα puis avance de ddd. Dans le repère ΩC=(C,x⃗,y⃗)\Omega_C = (C, \vec{x}, \vec{y})ΩC​=(C,x,y​) :
D⃗ΩC=(pq)=d.(cos⁡αsin⁡α)\vec{D}_{\Omega_C} = \begin{pmatrix} p\\ q \end{pmatrix} = d. \begin{pmatrix} \cos{\alpha} \\ \sin{\alpha} \end{pmatrix}DΩC​​=(pq​)=d.(cosαsinα​)

Modèles direct et inverse​

On considère un bras plan à 3 articulations rotoïdes, de longueurs de segments t1t_1t1​, t2t_2t2​ et t3t_3t3​.

  • Dans quel espace ? : le mécanisme à 3 degrés de liberté.
  • Quelles sont les variables ? : les entrées sont les angles articulaires (θ1,θ2,θ3)(\theta_1, \theta_2, \theta_3)(θ1​,θ2​,θ3​), les longueurs tit_iti​ étant des paramètres.
  • Poser le problème : dans le modèle direct, on souhaite trouver les coordonnées cartésiennes en fonction des θi\theta_iθi​ et des longueurs tit_iti​. Le modèle inverse lui fournit la position des différents joints θ\thetaθ en fonction de la position cartésienne de l'effecteur.

Modèle direct : sorties en fonction des entrées​

Enchaîner les changements de repère revient à composer, pour chaque segment, une rotation et une translation (produit des matrices de transformation).

X=(t1cos⁡θ1+t2.cos⁡(θ1+θ2)+t3.cos⁡(θ1+θ2+θ3)t1sin⁡θ1+t2.sin⁡(θ1+θ2)+t3.sin⁡(θ1+θ2+θ3)θ1+θ2+θ3)\mathcal{X} = \begin{pmatrix} t_1 \cos{\theta_1} + t_2 . \cos(\theta_1 + \theta_2) + t_3 . \cos(\theta_1 + \theta_2 + \theta_3) \\ t_1 \sin{\theta_1} + t_2 . \sin(\theta_1 + \theta_2) + t_3 . \sin(\theta_1 + \theta_2 + \theta_3) \\ \theta_1 + \theta_2 + \theta_3 \end{pmatrix}X=​t1​cosθ1​+t2​.cos(θ1​+θ2​)+t3​.cos(θ1​+θ2​+θ3​)t1​sinθ1​+t2​.sin(θ1​+θ2​)+t3​.sin(θ1​+θ2​+θ3​)θ1​+θ2​+θ3​​​

Modèle inverse : entrées en fonction des sorties​

Calculer le MGI revient à déterminer : [θ1,θ2,θ3]=FMGI(X1,X2,X3)[\theta_1, \theta_2, \theta_3] = \mathcal{F}_{MGI}(X_1, X_2, X_3)[θ1​,θ2​,θ3​]=FMGI​(X1​,X2​,X3​)

Le système est non linéaire (fonctions trigonométriques) et peut admettre plusieurs solutions (par exemple coude en haut ou coude en bas).

Posons le système d'équations :

{t1.cos⁡θ1+t2cos⁡(θ1+θ2)+t3cos⁡(θ1+θ2+θ3)−X1=0t1.sin⁡θ1+t2sin⁡(θ1+θ2)+t3sin⁡(θ1+θ2+θ3)−X2=0θ1+θ2+θ3=X3\begin{cases} t_1 .\cos{\theta_1} + t_2 \cos(\theta_1 + \theta_2) + t_3 \cos(\theta_1 + \theta_2 + \theta_3) - X_1 = 0 \\ t_1 . \sin{\theta_1} + t_2 \sin(\theta_1 + \theta_2) + t_3 \sin(\theta_1 + \theta_2 + \theta_3) - X_2 = 0 \\ \theta_1 + \theta_2 + \theta_3 = X_3 \end{cases}⎩⎨⎧​t1​.cosθ1​+t2​cos(θ1​+θ2​)+t3​cos(θ1​+θ2​+θ3​)−X1​=0t1​.sinθ1​+t2​sin(θ1​+θ2​)+t3​sin(θ1​+θ2​+θ3​)−X2​=0θ1​+θ2​+θ3​=X3​​

Pour résoudre ce problème, nous pouvons poser θ3=X3−θ1−θ2\theta_3 = X_3 - \theta_1 - \theta_2θ3​=X3​−θ1​−θ2​, ce qui ramène à deux équations à deux inconnues.
