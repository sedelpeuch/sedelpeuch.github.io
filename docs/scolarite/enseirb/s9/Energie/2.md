---
title: "Généralités sur les machines tournantes"
description: "Constitution d'une machine tournante (rotor, stator, entrefer, inducteur) et réversibilité moteur/générateur."
---

La constitution d'une machine tournante est la suivante :

+ Partie mobile rotor (peut être intérieur ou extérieur)
+ Partie fixe stator
+ Entrefer (mécanique, magnétique)
+ Inducteur ou excitation
+ Forme discoïde (« camembert ») ou cylindrique (« saucisson »)
+ Champ radial ou axial

Toutes les machines tournantes sont **réversibles** : elles peuvent fonctionner en moteur ou en générateur.
