---

Le module de bases de données du semestre 7 part de la conception avec le modèle entités-associations, passe au modèle relationnel et à la normalisation par les dépendances fonctionnelles, puis aborde l'algèbre relationnelle et le langage SQL. Les notes s'appuient en partie sur le cours de M. Mosbah et S. Lombardy ; les supports de l'enseignant traitent aussi des transactions, de la concurrence et de l'optimisation. Le projet, mené à quatre, consiste à modéliser puis implémenter sous MySQL une base de gestion des rencontres de handball entre les clubs d'une fédération, avec une interface web en PHP.
