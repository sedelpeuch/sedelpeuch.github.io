Compilation

IntroductionIntroduction à la compilation : intérêt, objectifs d'un compilateur et découpage en analyse lexicale, syntaxique, sémantique et représentation intermédiaire.Cours - Analyse lexicaleAnalyse lexicale : langages réguliers, construction de Thompson, déterminisation et minimisation d'automates, reconnaissance des lexèmes.Vidéo 4Grammaires algébriques : règles de production, plus petit point fixe, dérivations gauches, arbres de dérivation, ambiguïté et grammaire ETF des expressions arithmétiques.Vidéo 5Grammaires attribuées : attributs synthétisés et hérités, actions sémantiques Yacc et ordre d'évaluation postfixe sur l'arbre de dérivation.Vidéo 6.2Analyse ascendante par décalage-réduction : déroulé sur un exemple, conflits, table d'actions et manipulation des attributs sur la pile d'analyse.Vidéo 7.1Outils pour l'analyse sémantique et la production de code : actions sémantiques Lex/Yacc, table des symboles, récursion gauche, analyse de noms et de types.Vidéo 7.2Production de code pour les sous-blocs et les appels de fonction : variables locales en pile, pointeur d'environnement (frame pointer), adresse de retour.TD - Feuille 1TD de compilation : code 3 adresses pour les expressions, nombre de registres nécessaires, schémas de compilation des instructions de contrôle et compilation paresseuse des booléens.TD - Feuille 2TD de compilation : grammaires, ambiguïté, langage engendré, ambiguïté du « else pendant » et actions sémantiques Yacc produisant du code 3 adresses.
