Le cours de compilation du semestre 7 suit les étapes d'un compilateur, du texte source au code produit : analyse lexicale par automates, grammaires algébriques et analyse ascendante, grammaires attribuées et actions sémantiques Lex/Yacc, puis génération de code 3 adresses. Les notes reprennent le cours de David Janin, dont une partie était diffusée en vidéo. Le projet, mené en binôme, consiste à écrire un compilateur du mini-langage MyC vers du code 3 adresses.
