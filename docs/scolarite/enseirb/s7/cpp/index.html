Programmation C++

Notes du cours de programmation C++ du semestre 7. Elles s'appuient sur le support de cours et décrivent principalement le C++98 ; les évolutions importantes des standards récents (C++11 à C++20) sont signalées lorsqu'elles modifient les règles présentées.

La couche objet - Partie 1 : classes, héritage, classes de base virtuelles, fonctions et classes amiesNotes de cours C++ : déclaration de classes, encapsulation, héritage, classes de base virtuelles, fonctions et classes amies.La couche objet - Partie 2 : constructeurs, destructeurs, pointeur this, membres statiques, surchargeNotes de cours C++ : constructeurs et destructeurs, constructeur de copie, conversions, pointeur this, membres statiques et surcharge d'opérateurs.La couche objet - Partie 3 : opérateursNotes de cours C++ : surcharge des opérateurs d'affectation, de transtypage, de comparaison, d'incrémentation, d'appel de fonction, de déréférencement et d'allocation.La couche objet - Partie 4 : entrées/sorties, méthodes virtuelles, dérivation, classes abstraitesNotes de cours C++ : flux d'entrée/sortie, méthodes virtuelles, règles de dérivation, destructeurs virtuels, classes abstraites et pointeurs sur membres.Les exceptions en C++Notes de cours C++ : lancement et capture des exceptions, relance, spécifications d'exceptions, hiérarchies d'exceptions et exceptions dans les constructeurs.Les espaces de nommageNotes de cours C++ : espaces de nommage nommés et anonymes, alias, déclarations et directives using.Les templatesNotes de cours C++ : paramètres template, fonctions et classes template, fonctions membres template, instanciation implicite et explicite.
